لوحة مفاتيح سكاي — دليل البائع
==============================

محتويات المجلد
--------------
SkyAdmin.exe     لوحة التحكم: إنشاء المفاتيح وإدارتها وتجهيز نسخة العملاء (لك أنت فقط)
client\          البرنامج الذي يصل للعملاء (لا ترسله كما هو؛ استخدم زر «إنشاء نسخة العملاء»)
setup.sql        كود قاعدة البيانات (نفسه الذي ينسخه زر «نسخ كود الإعداد»)


الإعداد مرة واحدة فقط (10 دقائق)
--------------------------------
1) افتح https://supabase.com وأنشئ حساباً مجانياً، ثم New project.
   اختر اسماً وكلمة مرور لقاعدة البيانات، والمنطقة الأقرب لعملائك (مثلاً Central EU - Frankfurt).

2) شغّل SkyAdmin.exe ← تبويب «الإعدادات» ← اضغط «نسخ كود الإعداد (SQL)».
   في Supabase: القائمة الجانبية SQL Editor ← New query ← الصق (Ctrl+V) ← Run.
   يجب أن تظهر: Success. No rows returned

3) انسخ ثلاث قيم من Supabase والصقها في «الإعدادات» داخل SkyAdmin:
   - Project URL           : Project Settings ← Data API   (يشبه https://abcd.supabase.co)
   - المفتاح العام          : Project Settings ← API Keys  ← Publishable key (sb_publishable_...)
                              أو anon public في تبويب Legacy API Keys
   - المفتاح السري          : Project Settings ← API Keys  ← Secret key (sb_secret_...)
                              أو service_role في تبويب Legacy API Keys
   ثم اضغط «حفظ واختبار الاتصال» ← يجب أن يظهر ✅ الاتصال يعمل.

4) اضغط «إنشاء نسخة العملاء (ZIP)» واحفظ الملف. هذا هو الملف الذي ترسله لكل العملاء
   (نفس الملف للجميع؛ ما يميز كل عميل هو مفتاحه). أعد إنشاءه فقط إذا غيّرت مشروع Supabase.


البيع اليومي
------------
- تبويب «إنشاء مفاتيح»: اختر المدة (يوم / أسبوع / شهر / مخصص)، والعدد، واسم العميل ← «إنشاء».
  المفاتيح تُنسخ تلقائياً؛ أرسل المفتاح للعميل مع ملف SkySimple.zip.
- مدة المفتاح تبدأ عندما يفعّله العميل، لا عندما تنشئه. يمكنك تجهيز مفاتيح مسبقاً.
- العميل: يفك الضغط ← يشغّل SkySimple.exe ← يلصق المفتاح ← «تفعيل».


التحكم في المفاتيح (تبويب «المفاتيح»)
------------------------------------
اختر مفتاحاً أو أكثر من الجدول (Ctrl أو Shift للاختيار المتعدد) ثم:
- إيقاف            : يتوقف البرنامج عند العميل خلال نصف ساعة كحد أقصى، ولا يعمل حتى تعيد تفعيله.
- إعادة تفعيل       : يرجع المفتاح الموقوف للعمل.
- إعادة ضبط الجهاز  : إذا غيّر العميل جهازه أو أعاد تثبيت ويندوز. أول جهاز يفعّل المفتاح بعدها يُربط به.
- تمديد            : يضيف أياماً. المفتاح المنتهي يُمدد من اليوم، والفعّال من تاريخ انتهائه.
- حذف              : نهائي.
- نقر مزدوج على صف = نسخ المفتاح.  البحث يعمل بالمفتاح أو اسم العميل أو الـIP.

الجدول يعرض لكل مفتاح: حالته، تاريخ انتهائه، المتبقي، معرّف جهاز العميل، آخر IP، وآخر مرة اتصل فيها.


كيف تُمنع إعادة البيع
---------------------
أول جهاز يفعّل المفتاح يُربط به (بصمة من معرّف ويندوز واللوحة الأم وقرص النظام).
أي جهاز آخر يرى: «هذا المفتاح مفعّل على جهاز آخر». تغيير الراوتر أو الإنترنت لا يؤثر.
البرنامج يتحقق عند التشغيل وكل نصف ساعة؛ بلا إنترنت لمدة ساعتين يتوقف حتى يعود الاتصال.


تنبيهات مهمة
------------
- المفتاح السري (Secret / service_role) يتحكم في كل شيء. لا ترسله لأحد، ولا تضعه في نسخة العملاء.
  نسخة العملاء تحمل المفتاح العام فقط، وهو لا يستطيع قراءة الجدول ولا تعديله.
- مشروع Supabase المجاني يتوقف مؤقتاً إذا لم يُستخدم 7 أيام. ما دام عندك عملاء يشغّلون البرنامج فهو مستخدم.
  إن توقف: افتح لوحة Supabase واضغط Restore project.
- لا توجد حماية برمجية لا تُكسر: شخص خبير يستطيع تفكيك أي برنامج بايثون. هذا النظام يمنع المشاركة
  وإعادة البيع العادية، ويعطيك تحكماً كاملاً بالاشتراكات.
